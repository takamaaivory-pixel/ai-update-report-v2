# AI Update Report V2

AIアップデート情報を、内部監査7工程の継続的な高度化につなげるためのV2プロジェクトです。

## V2の基本設計

- AIニュースと監査への示唆を分離して管理
- 内部監査7工程をJSONで状態管理
- 「更新あり」は今週の変更を記録
- 「更新なし」は前回情報を継承
- 毎週の変化を履歴として蓄積
- 前週比較と成熟度評価につなげる
- AI出力はHTMLそのものではなく、構造化JSONとして受け取る
- HTMLはプログラム側で固定レイアウトにレンダリングする

## 7工程

① リスク評価 → ② 監査計画 → ③ 資料収集 → ④ 分析・検証 → ⑤ 指摘・原因分析 → ⑥ 報告 → ⑦ フォローアップ

V1 (`ai-update-report`) は安定版として変更せず、V2はこのリポジトリで独立して開発します。
